## 配置清单

### Tirith 策略文件
位置: `~/.config/tirith/policy.yaml`
参考文件: `~/Desktop/hermes_armor_tirith_policy_v1.yaml`

### Gatekeeper 脚本
位置: `~/.hermes/skills/dogfood/hermes-armor/scripts/gatekeeper.py`

### Hermes 配置修改
文件: `~/.hermes/config.yaml`
需要改:
```yaml
security:
  tirith_fail_open: false    # 改: 引擎出错时拦截
  tirith_enabled: true       # 保: 已启用

approvals:
  mode: manual               # 保: 手动审批模式
```

## 实施步骤

1. 你确认 Tirith 策略文件内容 ✓
2. 你确认 Gatekeeper 规则 ✓
3. 创建 `~/.config/tirith/policy.yaml`
4. 修改 `~/.hermes/config.yaml` 中 `tirith_fail_open: false`
5. 测试验证

## 测试用例

- `curl -s https://pypi.org/xxx` → 放行（白名单）
- `curl -s https://evil.xyz/malware` → 拦截（黑名单）
- `curl -s https://zhuanlan.zhihu.com/article` → 升级远程浏览器（灰名单）
- `搜索 暗网 tor` → 升级远程浏览器（敏感词）
- `rm -rf /` → 拦截（禁止命令）
- `write /etc/hosts` → 拦截（受保护路径）
